# #ABSON — Wedding Website

Wedding website for Abhilasha & Sovon.

- Cover photo preserved.
- The 9 newly supplied couple photos are included once each; no gallery photo is repeated.
- The supplied `Din Shagna Da Phillauri 320 Kbps.mp3` is included as `assets/wedding-song.mp3`.
- Music starts when the guest taps **ENTER INVITATION** and can be paused/resumed with the music button.
